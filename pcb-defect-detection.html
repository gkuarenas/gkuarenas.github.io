PCB Defect Detection

A YOLOv8-based defect detector for printed circuit boards, tuned with TensorRT for real-time inspection.

Overview

Printed circuit boards need defect inspection during manufacturing, and manual visual inspection does not hold up as board complexity and production volume grow. This project trains a YOLOv8 model to spot six common PCB defect types and speeds it up with TensorRT for real-time use on a production line.

Guillaume was first author and led the student research team. He worked across dataset preparation, augmentation, model training, testing, evaluation, and the paper itself. The full author list, including faculty advisers, is in the linked paper.

Problem & Approach

Problem: Manual visual inspection of PCBs is slow and inconsistent, and it does not scale with production volume. Reference-based automated inspection needs a stored template per board design and breaks down with lighting or alignment changes. Both approaches struggle to catch small, varied defects reliably.

Approach: Build a large, augmented training set covering six defect types, train a YOLOv8s detector on it, then convert the trained model to TensorRT so it runs fast enough for real-time inspection without giving up much accuracy.

Key Features

  • 10,668 source images covering six defect types, augmented to 5,070 images and split into a 1,663-image training set
  • YOLOv8s detector trained end to end on the augmented dataset
  • TensorRT conversion for faster, smaller real-time inference

Results & Outcomes

  • YOLOv8s reached mAP50 of 98.6% and mAP50-95 of 64% across all six defect classes
  • The TensorRT version reached mAP50 of 98.5%, a drop of only 0.1%
  • TensorRT cut inference time from 7.6 ms to 6.7 ms and model size from 87.5 MB to 53.1 MB, a reduction of about 39.3%
