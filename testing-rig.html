A ~$250 automated test bench for characterizing soft sensor materials, replacing $10,000–$14,000 industrial robotic rigs.

Overview

This testing rig automates soft-material characterization (sensitivity, hysteresis, repeatability) for tactile sensor development. It combines a repurposed 3D printer, a load cell, and computer-vision marker tracking to run unattended, multi-hour test protocols with no operator. A paper on the system has been submitted to VTCA 2026.

Problem & Approach

Problem: Published protocols on visuotactile sensors rely on industry-grade robotic arms costing $10,000–$14,000 per rig. The manual fallback, a force gauge, still takes an estimated 25 hours per specimen, since there's no automated depth control or synchronized force-position logging.

Approach: A repurposed 3D printer performs precise indentation while a load cell and computer-vision marker tracking capture force and deformation, contact-free. The whole workflow, calibration, testing, and logging, runs unattended.

Key Features

  • Self-calibrating depth search per position, no manual setup
  • Automated safety interlocks (movement, tracking-loss, auto-retry)
  • Crash-safe, resumable sessions via atomic checkpointing
  • Modular, open-source software, released on GitHub

Results & Outcomes

  • Cost: $250 build vs. $10,000–$14,000 industry-grade rigs, 97.5–98.2% cheaper 
  • Time: ~90% less time, ~10x faster. 
  • Scale: ~19 million marker-position measurements across 4 materials, infeasible by hand
