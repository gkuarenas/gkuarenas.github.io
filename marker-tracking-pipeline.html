Marker Tracking Pipeline

A sub-pixel marker detection and tracking pipeline for a visuotactile sensor, built on Gaussian fitting and Kalman filtering.

Tech Stack
Python OpenCV NumPy SciPy Kalman Filtering

Overview

GripVT is a wearable visuotactile sensor that reads hand grip force from how a soft silicone band deforms on the forearm. This pipeline is the computer-vision core inside GripVT: it finds and tracks a 99-point marker grid printed on the band, frame by frame, and turns raw camera video into per-marker displacement and size data. It is ongoing graduate research work at National Chin-Yi University of Technology, under Guillaume's DLSU thesis.

Problem & Approach

Problem: GripVT reads grip force from how the marker band deforms, so the pipeline must find each of the 99 markers' position and size every frame, precisely enough to catch a small muscle bulge under a 5% grip. The band is worn and removed between sessions, so lighting and marker position shift each time.

Approach: Undistort each frame, rotate it to a common orientation, convert it to grayscale, then crop and clean it up with morphology to isolate candidate marker blobs. Fit a closed-form 2D Gaussian to each blob with the Caruana log-parabola method, reading off a sub-pixel center and size with no threshold to tune, and fall back to the blob centroid when a fit is invalid. Capture a 15-frame baseline to lock each marker's identity and starting position, then track every marker frame to frame with a Kalman filter and gated Hungarian assignment, computing displacement and size change relative to that baseline.

Key Features

  • Sub-pixel marker center and size from a closed-form 2D Gaussian fit (Caruana log-parabola method), no iteration needed
  • Threshold-free sizing: the fit reads size directly from blob intensity, with no threshold to tune
  • Robust baseline capture: a 15-frame median with a presence filter, so one noisy frame cannot poison a session
  • Gated Hungarian tracking: an explicit reject option stops a missing or stray detection from corrupting a neighboring match

Results & Outcomes

  • Delivers sub-pixel position and threshold-free size for all 99 markers, every frame
  • Baseline capture uses a 15-frame median with a presence filter, so one noisy frame cannot poison a whole session
  • Gated Hungarian assignment stops a missing or stray detection from corrupting a correct neighboring match
  • This is in-progress thesis work. There is no final accuracy number yet, since tuning against real GripVT footage is still pending
