Marker Tracking Pipeline

A sub-pixel marker detection and tracking pipeline for a visuotactile sensor, built on Gaussian fitting and Kalman filtering.

Overview

This pipeline finds and tracks a 99-point marker grid, frame by frame, and turns raw camera video into per-marker displacement and size data. It is the computer-vision core inside GripVT, a wearable visuotactile sensor, and is ongoing graduate research work at National Chin-Yi University of Technology, under my master's thesis.

Problem & Approach

Problem: GripVT reads grip force from how the marker band deforms, so the pipeline must find each of the 99 markers' position and size every frame, precisely enough to catch a small muscle bulge under a 5% grip. The band is worn and removed between sessions, so lighting and marker position shift each time.

Approach: Undistort each frame and rotate it 90° to match the region-of-interest orientation, then crop, denoise, flatten illumination, and binarize with morphology and a mask to isolate candidate marker blobs. Fit a closed-form 2D Gaussian to each blob with the Caruana log-parabola method, reading a sub-pixel center and size off the raw, unmasked frame with no threshold to tune, and fall back to the connected-component centroid and area when a fit is invalid. Capture a 15-frame baseline to lock each marker's identity and starting position, then track every marker frame to frame with a Kalman filter and gated Hungarian assignment, computing pixel-space displacement and area change relative to that baseline.

Key Features

  • Sub-pixel marker center and size from a closed-form 2D Gaussian fit (Caruana log-parabola method), no iteration needed
  • Two-path detection: marker positions are located on the cleaned, masked image, but size and intensity are measured from the raw frame, avoiding bias from binarization
  • Robust baseline capture: a 15-frame median with a presence filter, so one noisy frame cannot poison a session
  • Gated Hungarian tracking: an explicit reject option stops a missing or stray detection from corrupting a neighboring match

Results & Outcomes

  • Delivers sub-pixel position and threshold-free size for all 99 markers, every frame
  • Baseline capture uses a 15-frame median with a presence filter, so one noisy frame cannot poison a whole session
  • Gated Hungarian assignment stops a missing or stray detection from corrupting a correct neighboring match
  • Validated across 80 real GripVT sessions from 8 participants: detector self-calibration passed on the first attempt every session, and markers needed the autofill fallback in only 0.002% of frames (5 of 302,916)
